# 🎓 Student Performance Management System

A desktop-based Student Performance Management System built using Python and Tkinter. This application allows users to manage student records, store marks, search for students, delete records, and calculate average marks through a simple graphical user interface.

## 🚀 Features

- **Add Performance:** Add student names and their marks.
- **View Performance:** Display all saved student records.
- **Search Performance:** Search for a student using their name.
- **Delete Performance:** Remove selected student records.
- **Calculate Average:** Calculate the average marks of all students.
- **Data Persistence:** Store student records in a JSON file.
- **Input Validation:** Check empty fields and ensure marks are numeric.

## 🛠️ Technologies Used

- Python 3
- Tkinter – Graphical User Interface
- JSON – Data Storage
- Object-Oriented Programming (OOP)
- Exception Handling
